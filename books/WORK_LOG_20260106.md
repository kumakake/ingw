# 作業ログ 2026-01-06

## 概要
クレジットカード以外の決済（銀行振込、特別対応等）に対応するため、管理者が手動でユーザーの投稿権限を有効化できる機能を実装。

## 背景
- 現在はStripe決済（クレジットカード）のみ対応
- 銀行振込などクレジットカード以外での決済に対応する必要が発生
- 管理者がライセンス一覧画面から手動で有効化できる機能を追加

## 採用方式
**オプション1: 別フラグ追加方式**を採用
- `manual_subscription_enabled` フラグを追加
- 既存のStripe連携とは独立して動作
- どちらかが有効なら投稿可能（OR条件）

### 選定理由
- 既存ロジックへの影響最小（Stripe連携は変更不要）
- 運用の柔軟性（Stripe契約中でも手動で延長サービス可能）
- シンプルな実装
- ロールバックが容易

## 実装内容

### 1. DBマイグレーション
**ファイル**: `db/migrations/20250106_add_manual_subscription.sql`

```sql
ALTER TABLE users ADD COLUMN manual_subscription_enabled BOOLEAN DEFAULT false;
ALTER TABLE users ADD COLUMN manual_subscription_end TIMESTAMP;
ALTER TABLE users ADD COLUMN manual_subscription_note TEXT;
```

| カラム | 型 | 説明 |
|--------|-----|------|
| manual_subscription_enabled | BOOLEAN | 手動有効化フラグ |
| manual_subscription_end | TIMESTAMP | 有効期限（NULL=無期限） |
| manual_subscription_note | TEXT | 備考（振込日、請求書番号等） |

### 2. User.js修正
**ファイル**: `src/models/User.js`

#### hasActiveSubscription() 修正
手動有効化チェックを優先的に追加：
```javascript
// 1. 手動有効化チェック（優先）
if (manual_subscription_enabled) {
  if (!manual_subscription_end) return true;  // 無期限
  if (new Date(manual_subscription_end) > now) return true;  // 期限内
}
// 2. Stripeチェック（既存ロジック）
```

#### 新規メソッド追加
- `setManualSubscription(userId, endDate, note)` - 手動有効化
- `disableManualSubscription(userId)` - 手動解除

### 3. License.js修正

#### CSS追加

#### 契約状態バッジ

#### モーダルダイアログ
- 有効期限入力（日付ピッカー、空欄=無期限）
- 備考入力（任意）

## 投稿時の期間チェックフロー

```
WordPress → 投稿リクエスト
    ↓
validateLicenseAndSubscription ミドルウェア (src/routes/api.js)
    ↓
User.hasActiveSubscription(userId)
    ↓
┌─ 手動有効化チェック（優先）
│   ├─ enabled=true & 期限なし → ✅ 投稿可能
│   ├─ enabled=true & 期限内 → ✅ 投稿可能
│   └─ enabled=true & 期限切れ → 次へ
│
├─ Stripeトライアルチェック
│   └─ trialing & trial_end未来 → ✅ 投稿可能
│
└─ Stripeアクティブチェック
    └─ active & period_end未来 → ✅ 投稿可能

いずれも該当しない → ❌ 403エラー
```
