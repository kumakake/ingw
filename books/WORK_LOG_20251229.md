# 作業ログ 2024-12-29

## 課題

**1つのFacebookアカウントから複数のInstagramアカウントへ投稿できない問題**

### 現象
- 複数のFBページを作成し、それぞれ異なるInstagramアカウントとリンク
- OAuth認証後、最後にリンクしたInstagramアカウントにしか投稿できない

### 原因調査

データベーススキーマとモデルの実装を調査した結果、以下の問題を特定：

| 箇所 | 問題点 |
|------|--------|
| `db/schema.sql:18` | `facebook_user_id UNIQUE NOT NULL` - 1ユーザー1レコードの制約 |
| `InstagramUser.upsert()` | `facebook_user_id`で検索し、存在すれば上書き更新 |
| `InstagramUser.update()` | `facebook_user_id`をキーに全データを上書き |

### 動作フロー（修正前）

```
OAuth完了時の処理:
1. ページA (Instagram A) → upsert → 新規作成 ✅
2. ページB (Instagram B) → upsert → 既存レコードを上書き！
3. ページC (Instagram C) → upsert → 既存レコードを上書き！
結果: Instagram C のみ保存される
```

## 修正内容

### 1. データベーススキーマ変更 (`db/schema.sql`)

**変更前:**
```sql
facebook_user_id VARCHAR(255) UNIQUE NOT NULL,
...
facebook_page_id VARCHAR(255) NOT NULL,
```

**変更後:**
```sql
facebook_user_id VARCHAR(255) NOT NULL,          -- UNIQUE削除
...
facebook_page_id VARCHAR(255) UNIQUE NOT NULL,   -- UNIQUEに変更
```

### 2. モデル修正 (`src/models/InstagramUser.js`)

#### `findByFacebookUserId` - 複数レコード対応

```javascript
// 変更前: return result.rows[0];  // 1件のみ
// 変更後: return result.rows;     // 全件（配列）
```

#### `upsert` - facebook_page_id をキーに変更

```javascript
// 変更前: findByFacebookUserId で検索
// 変更後: findByPageId で検索
static async upsert(userData) {
  const existing = await this.findByPageId(userData.facebookPageId);
  if (existing) {
    return await this.updateByPageId(userData.facebookPageId, userData);
  }
  return await this.create(userData);
}
```

#### `updateByPageId` - 新規メソッド追加

```javascript
static async updateByPageId(facebookPageId, userData) {
  // facebook_page_id をキーに更新
}
```

### 3. APIコントローラー修正 (`src/controllers/apiController.js`)

`getInstagramUserId` メソッドを複数アカウント返却に対応：

**変更前（単一オブジェクト）:**
```json
{
  "success": true,
  "data": { "instagramUserId": "...", ... }
}
```

**変更後（配列）:**
```json
{
  "success": true,
  "count": 3,
  "data": [
    { "instagramUserId": "...", "facebookPageId": "page1", ... },
    { "instagramUserId": "...", "facebookPageId": "page2", ... },
    { "instagramUserId": "...", "facebookPageId": "page3", ... }
  ]
}
```

### 4. マイグレーションファイル作成

`db/migrations/001_multi_instagram_accounts.sql`

```sql
-- facebook_user_id の UNIQUE制約を削除
ALTER TABLE instagram_users 
DROP CONSTRAINT IF EXISTS instagram_users_facebook_user_id_key;

-- facebook_page_id に UNIQUE制約を追加
ALTER TABLE instagram_users 
ADD CONSTRAINT instagram_users_facebook_page_id_key UNIQUE (facebook_page_id);
```
